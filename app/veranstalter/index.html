    Anmelden

    Sie melden sich mit Ihrer E-Mail-Adresse an. Sie erhalten einen Anmeldelink, ein Passwort brauchen Sie nicht.

    In der Demo wird keine E-Mail verschickt.

    Veranstaltung anlegen und Programm hochladen

    Laden Sie Ihr Programm hoch, so wie es vorliegt: PDF, Word, Excel. Oder nennen Sie die Adresse Ihrer Programmseite.

        Veranstaltungscodes festlegen

        Mit dem Code finden Teilnehmende Ihr Programm, z. B. von Plakat, Leinwand oder Programmheft. Sie können mehrere Codes festlegen. Den Code erhalten Sie sofort, auch wenn das Programm noch nicht fertig ist. Bis zur Aktivierung erscheint „Programm folgt“.

          Pläne und Dokumente (optional)

          Laden Sie Lagepläne, Standpläne oder eine Anfahrtsbeschreibung als PDF hoch. Teilnehmende finden sie oben im Programm.

          • Nur PDF, höchstens 10 MB, besser unter 3 MB (Messe-WLAN)
          • PDFs mit eingebetteten Skripten werden aus Sicherheitsgründen abgelehnt

          Ihre Dokumente

          • Lageplan Kongresszentrum (PDF, 21 KB, Beispiel)

          In der Demo wird nichts hochgeladen. Die Prüfung läuft nur in Ihrem Browser.

          Sponsorflächen (optional)

          Die Flächen gehören Ihnen, Sie können sie an Ihre Sponsoren weitergeben. Jede Fläche ist als „Anzeige“ gekennzeichnet. Logos werden unverändert übernommen, Tracking ist ausgeschlossen.

          Das Logo wird nur in Ihrem Browser angezeigt, in der Demo wird nichts hochgeladen.

          Und danach?

          • Programmänderungen: neue Datei hochladen oder direkt im Editor ändern. Teilnehmende sehen sofort den neuen Stand mit Hinweis.
          • Nach der Veranstaltung bleibt das Programm sichtbar, bis Sie deaktivieren.
          • Weitere Veranstaltungen legen Sie genauso an, jeweils mit eigenem Preis.
          • Fragen oder Probleme: über „Hilfe“ im Veranstalter-Bereich, wir antworten per E-Mail.
